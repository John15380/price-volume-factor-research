# code2_new.py 使用说明

## 运行

在本目录使用已有的 quant 环境：

```sh
/opt/homebrew/Caskroom/miniconda/base/envs/quant/bin/python code2_new.py
```

默认运行2016—2018年中证500历史成分、六个高频因子、5/10/20交易日调仓，输出至 `results_code2_new/`。相对数据路径以脚本位置为基准，原始 `code2.py`、旧缓存及旧图片保持原样。

缩短区间、只运行一个因子的示例：

```sh
python code2_new.py --start 2016-01-04 --end 2016-03-04 \
  --factor HF_SmartMoney --period Weekly --output-dir results_code2_new_smoke
```

支持重复指定 `--factor` 和 `--period`；`--index 300` 切换至沪深300；`--help` 显示全部选项。单因子流程依赖 `numpy pandas pyarrow numba scikit-learn matplotlib tqdm`；启用模型时另需 `xgboost`。

## 修正内容

- 信号于T日收盘后形成，T+1开盘执行。IC对应T+1至T+N+1开盘收益；调仓日固定在独立交易日历上，不因未来收益缺失或因子缺失而移动。
- 利用当日除权参考昨收重建连续开盘/收盘价格，调整因子仅使用当时及过去信息。中途未知行情缺口无法可靠区分漏记涨跌与除权，程序会要求补全数据，不静默制造收益。
- 先按当时因子分组，之后才配对未来收益计算IC。未来买卖价格缺失不改变信号组合，IC文件同时记录配对覆盖率。
- 五个多头组及理论多空均维护现金和持仓，按实际成交金额逐次扣费。买入失败留现金；减仓失败保留仓位、逐日重试；新的调仓指令覆盖旧指令。
- 日频净值、年化收益、Sharpe与回撤来自同一日收益账本。回撤包含初始资金；年化收益为几何年化；Sharpe使用算术日超额收益。
- 风格变量先在完整个股行情上计算，再筛选动态股票池。因子滚动窗口按交易日历对齐，缺失日不会被压缩成“最近20条”。缺失因子和控制变量不填0伪造信号。
- Smart Money使用分钟真实成交额；去极值采用中位绝对偏差。分组依旧采用五分组，Group5为低因子多头；未改成Top50。

## XGBoost 多因子合成

```sh
python code2_new.py --with-xgboost --output-dir results_code2_new_report
```

该命令先完整运行六个单因子的流程，再分别训练5/10/20日预测模型，并在共同样本上比较模型和单因子。已完成单因子流程时，可用 `--model-only` 复用同目录的预处理因子。

模型实现位于 `code2_xgboost.py`。输入为六个中性化因子；目标为相应N日连续开盘收益减去该信号日截面平均收益。每月用最近12个月历史重新训练，要求标签实际退出日严格早于预测月首个交易日。固定使用100棵树、深度5、学习率0.05，不使用测试期调参或早停。

默认样本外预测从2017年2月开始。模型与单因子的对照均使用同一预测期、同一六因子完整股票样本、同一调仓日历及同一成本规则；模型按预测分数高值做多。输出位于 `xgboost/`（预测、逐月训练范围、特征重要性、模型文件）及 `comparison/`（21个因子/期限组合与126条组合账本）。

## 输出及解释

根目录的 `summary.csv` 汇总每个因子、期限、组合的费后绩效；`run_config.json` 保存参数和源码摘要；`processed_features.parquet` 保存预处理因子。

`factor_correlation.csv/png` 保存逐日截面Spearman相关系数的等权平均及热力图。

每个“因子/期限”目录包括：

| 文件 | 内容 |
| --- | --- |
| `signal_groups.parquet` | 信号日分组，只依赖当日及历史信息 |
| `ic.csv` | 完整N日期限的原始IC、方向调整IC、RankIC及覆盖率 |
| `daily_ledger.csv` | 每日净值、收益、现金、多空市值、费用、换手及受阻/缺行情持仓数 |
| `trades.parquet` | 实际成交的股票、连续价格单位、价格、金额和费用 |
| `nav.png` | 从上述账本绘制的每日费后净值 |

低值做多时，原始IC可能为负；方向调整IC统一为“值越大越看好”。ICIR仅输出每期IC均值/标准差，不默认乘年化系数。

每个多头组初始资金为1。理论多空在调仓时目标多头50%、空头50%，总敞口100%；它与旧代码的“多头100%减空头100%”敞口不同，不能直接比较收益数值。仓位受阻时实际敞口和中性程度会偏离目标，应查看账本。

数据末日开盘尝试平仓，最后一段持有期可能不足N日；受阻头寸仍按日末估值保留，汇总表记录 `FinalPositions` 和 `FinalPendingReductions`。未知的尾部行情按最近估值保留，`StalePositionDays` 明确记录相关敞口，不应当作已清算收益。

`HasStaleValuations=True` 表示绩效依赖缺失行情时沿用最近价格的假设，不能据此认定该资产最终清算价值；`FullyLiquidated=False` 表示样本结束仍有持仓。现有真实数据确实存在这两种情形，解读汇总收益时须同时查看这两列。

## 数据能够支持的假设

默认每次买/卖费率各0.0015，即一次完整买卖合计0.003；可用 `--one-way-fee` 调整。默认年借券费率和无风险利率均为0，可分别通过 `--annual-borrow-fee`、`--annual-risk-free` 设置。

现有日行情没有精确涨跌停价、成交队列和借券供应。代码默认用相对当日参考昨收的4.9%开盘跳空作方向性过滤：向上跳空达到阈值不买入，向下跳空达到阈值不卖出。`--open-gap-limit` 可调整这一保守代理，代理不能保证识别所有真实涨跌停或成交机会。理论空头假定可借券。

连续价格单位相当于除权权益即时再投资；采用可分割份额，不模拟整手、现金分红到账时点、冲击成本和税费明细。这些假设在代码头部及每次运行输出中均有记录。

## 验证

```sh
python -m unittest discover -s tests -p 'test_code2_new.py' -v
```

测试覆盖除权、停牌、未知数据、历史窗口、真实成交额、固定调仓日、IC期限、未来信息隔离、首次费用、权重漂移、未成交订单及账本与绩效一致性。
