# 八因子与XGBoost：2016—2017训练，2018回测

当前唯一源码为 `code2_new.py`，最终报告为根目录 `report.pdf`。报告沿用原模板的Fandol与Latin Modern字体，主要表格保持正文五号字。

## 当前实验

候选为SmartMoney、CPV、CDPDP′、IdealAmplitude、IdealReversal、CDPDP-4、LowAmpMomentum、Skewness，共八个因子。CDPP不进入因子输出、相关性去重、调参或模型训练。其余因子的数学定义与实现约定保留。

三池分别为历史沪深300、中证500、本地覆盖全A股；调仓和标签期限为5、10、20交易日。每个因子以及XGBoost均保留全部九组配置，共81组2018结果。

- 每组给出IC、ICIR、RankIC、RankICIR及有效观测数，多空累计、年化收益、年化波动、夏普、最大回撤和日均换手。
- IC/RankIC按调仓信号日与匹配的N日开盘收益计算；IR按 `mean / sample_std * sqrt(250/N)` 年化，不把N日标签当作日收益。
- 表格保留原始因子方向。LowAmpMomentum及模型高值做多，其余低值做多，因此负RankIC可代表有效排序。
- 多空净值按逐日真实持仓及现金记账，年化按250交易日几何复利，夏普按日算术收益和样本标准差计算。
- 五分组等权，Q1看好、Q5看空，方向预先固定、保留真实盈亏，不取绝对值，多空两腿各目标100%。T收盘信号、T+1开盘执行；受阻买入留现金，受阻减仓重试。
- 手续费每次买卖各0.0015，完整往返合计0.003，两腿均按实际成交金额计费。借券费、融资费均设0，不执行费用情景比较。
- 多头保留ST、停复牌及真实涨跌停价；空头的新开、增加及回补取消这些成交许可和开盘价格下限、融券资格、券源约束。有有效开盘报价即按报价成交，缺报价不以沿用估值虚构成交。该结果采用理论卖空假设。

CDPDP′为两个条件相关子项各自标准化后相加，CDPDP-4为四象限子项 `Z(++)-Z(+-)-Z(-+)+Z(--)`。20日均值、退化相关补0、5MAD及总市值处理沿用公开实现约定；本报告不是研报自然月五分组的逐项绩效复制。

## XGBoost训练

最终训练信号位于2016—2017，标签退出日严格早于2018-01-01；训练行情对象本身不包含2018。目标为个股未来N日开盘收益减同日截面均值，平方误差训练，日期总样本权重相同。

2017年Q1/Q2/Q3作为外层时间验证。每个季度之前，只用当时已实现标签，在最后三个21交易日内层窗口中调参、早停和去重；每个内层折也purge未实现的训练标签。外层模型分别在2016-12-30、2017-03-31、2017-06-30冻结，最终模型在2017年末另行搜索、拟合。2018全年模型冻结，不重新训练、早停或选因子。

相关阈值为0.70/0.80/0.90，因子预算4/6/8项，与树参数联合搜索。每次96组候选，16组晋级三折；初筛300树/25轮早停，精筛1200树/50轮早停。RMSE用于早停，三折日RankIC均值减0.1倍折间标准差用于参数选择，最终树数取三折最佳树数中位数。三池三期限共36次搜索、5184次内层拟合，另有27个外层模型与9个最终模型。八因子模型在v13中已重新训练。本轮只改变分组及执行：核对与v13学习代码的AST一致、模型和输入哈希后，以原冻结模型重新生成预测，并与已保存预测逐值核对一致；重跑所有组合。没有复用含CDPP的模型，也没有重新选参。

仅删除CDPP列时，代码核对旧特征缓存哈希、交易输入和其余因子数学签名后投影为八列；不会重新计算未变化的分钟因子。模型输入和模型元数据均校验不包含CDPP。

## 表格和统一画图规则

所有81组结果完整列出。每个因子或XGBoost自身2018费后多空年化最高的配置加粗，并列按固定顺序处理。

所有展示图只用同一组股票池及期限：对九项策略在每个配置下的2018费后多空年化等权平均，选均值最高的配置。这个平均值仅用于选图，不是一个新组合的收益。图中的配置可以不同于该因子的加粗行。表格加粗和选图均为2018结果的事后展示，不用于训练或超参数选择。

每项策略的一张图上半部叠加Q1—Q5、多空及同池等权背景净值，下半部为五分组费后累计收益柱状图。每张图明确股票池和期限。保持相同配置便于横向观察因子差异。

## 运行

```sh
conda activate quant
python code2_new.py --compare-universes --reuse-frozen-models
python code2_new.py --report
python code2_new.py --self-test
```

`make all`执行三池实验与报告，`make test`运行内置测试，`make report`核验账本并编译报告。单池重跑可用 `--universe 300`、`--universe 500`、`--universe all`。三池实验按执行协议和完整源码哈希判断复用。`--reuse-frozen-models`只允许学习AST与v13完全一致时使用；学习逻辑改变后需去掉此选项重新训练。PDF编译需要XeLaTeX，中间文件仅写入系统临时目录。
