## 运行

```sh
conda activate quant
python code2_new.py --compare-universes
python code2_new.py --report
```

`make all`执行三池实验、比较和报告；`make test`运行85项内置测试；`make report`核验当前结果并编译根目录report.pdf。报告需要XeLaTeX，编译中间文件放系统临时目录并自动清理。

仅改动执行规则时，可运行`python code2_new.py --compare-universes --replay-execution`。它逐项核对v10（d607edd）的15段学习函数AST、输入文件和全部模型权重哈希，校验通过后重新生成所有预测并重跑回测；不依赖未跟踪的预测缓存。学习代码或输入不符时拒绝复用。默认命令仍支持从头完成36次搜索。本轮执行层修订采用该核验后重放方式。

单独重跑某一池：

```sh
python code2_new.py --universe 300 --with-xgboost
python code2_new.py --universe 500 --with-xgboost
python code2_new.py --universe all --with-xgboost
python code2_new.py --self-test
```

三池比较仅在协议及完整代码SHA-256一致时复用已完成实验；单池命令重新运行其模型和回测。`--universe`默认500，`--output-dir`指定实验结果根目录，报告命令读取默认的`results/`。`--prepare-only`只准备或校验输入。原始输入或因子定义变更后应清除对应input目录再重建。个股滚动分量可复用，各池截面处理分别重算。

## 固定训练及选型

- 最终训练信号位于2016—2017，标签退出日严格早于2018-01-01；训练标签的行情对象本身不包含2018。
- 外层验证为2017年Q1、Q2、Q3。每个季度种子信号收盘前，仅取退出日不晚于该日的历史标签；在这部分历史最后三个21交易日窗口内独立调参、早停和筛因子。每个内层折的训练标签也须在内层验证开始前实现。
- 每次搜索96候选、前16组晋级三折；早停使用内层验证RMSE，参数按内层RankIC稳定性选择。每折单独计算相关性去重与因子质量，获胜候选的三折最优树数中位数用于外层冻结模型。
- 外层Q1/Q2/Q3分别在2016-12-30、2017-03-31、2017-06-30冻结参数和模型；季度内不使用本季或后续季度收益选参。边界种子信号归属于下一季度模型。
- 外层预测用于选股票池和期限：每个因子及XGBoost在9个候选中，按验证费后多空年化择优。此步骤不读取2018收益。
- 2017年末另用Q1/Q2/Q3三折为2018最终模型选参，再用2016—2017完整已实现样本筛因子、拟合一次；这套最终参数不回填此前外层预测。2018全年权重和参数冻结，因子及动态成分仍按当日信息更新。
- 三池共36次搜索（27次外层历史内部搜索、9次最终搜索）、5184次内层验证拟合；另拟合27个外层验证模型和9个最终固定模型。2018重训次数为0。

训练期验证参与联合选型，只用于选择。当前是既有样本上的固定划分回测，不将历史验证数字视为新增时期的前瞻证据。

v10已修复验证期参数前视。v11进一步修订卖空执行；旧59.58%累计收益、4.79夏普仅作为固定审计对象在无独立融券价格约束下的对照，不再作为主比较的交易可实现表现。当前主比较使用价格约束后的2017外层验证重新选池和期限。

修订后，XGBoost按2017验证选出沪深300、20交易日：验证多空年化29.74%，2018累计12.39%、年化12.77%、夏普0.92、最大回撤-7.54%，平均净多敞口32.58%。原固定审计对象全部A股、5日的同信号价格约束压力测试则为累计19.45%、年化20.07%、夏普1.66，平均净多敞口40.64%；不以2018收益更高为由重新选回该配置。两者均未补齐历史券源。

## 因子与交易

候选共9项：SmartMoney、CPV、CDPDP′、IdealAmplitude、IdealReversal、CDPP、CDPDP-4、LowAmpMomentum、Skewness。尾部收益不进入研究。低振幅长端动量高值做多，其余低值做多；模型高分做多，方向不依2018结果翻转。

十组等权，G10为看好组，每个多头组目标100%；理论多空多、空各100%，总名义仓位200%。T日收盘信号，T+1开盘执行。2017最后交易日生成首次测试信号，2018首个交易日开盘建仓。使用历史ST、09:30停复牌及真实涨跌停价；受阻买入留现金，退出受阻保留重试，末日尝试退出。假定借券及融资可得，未另估借券和冲击成本。

新增空头和普通持仓卖出分别控制。默认`opening_price`模式要求原始开盘价不低于日行情的参考前收盘价，同时满足普通卖出和ST准入；未知参考价禁止新开、加空。该约束不阻止普通多头卖出或空头回补，拒单不补选、不重新等权。实际多空敞口及净敞口随账本输出。

开盘限价条件只是必要条件，仍没有订单队列及成交容量证据。当前缺少真实历史融券资格、账户券源、保证金、融资成本和冲击数据，因此所有主结果均为“开盘价格约束、券源仍假定可得”的历史压力测试；修订夏普也不代表实盘夏普。指数成分并集不作历史融券名单。

严格券源模式可用`--short-policy verified_inventory --short-inventory FILE --initial-capital 1000000`。CSV字段为`TradingDay,SecuCode,AvailableAt,Eligible,MaxShortShares`；日期/时间使用中国本地时间，Eligible为0/1，MaxShortShares为该账户当日允许的**总借券持仓股数上限**，不是额外可借数量。仅接受当日09:15前已知的记录，不前向填充；缺失记录禁止新增借券，但不虚构召回。已知上限收紧会回补，受阻后重试。按原始股数、当日复权尺度和初始人民币资金换算容量。未提供文件时严格模式直接报错，避免把缺数据后的单边组合冒充已验证多空。

**手续费为买卖各0.0015，完整往返0.003。** 年化按250交易日几何复利，夏普按算术日收益计算，只保留当前口径。借券费情景按前收盘空头市值、250交易日均摊计提，并非真实合同的自然日账单；现金未进一步区分信用账户的担保及受限融券卖出款。

基准是同池全体合格股票等权，不按因子缺失或模型预测过滤，使用相同日历、开盘成交限制、现金处理及费用；它不是官方市值加权指数。另以相同信号及限制、费用率为0重跑基准。预测覆盖差异也会影响相对收益。

## 结果文件

各池分别有`validation/`、`test/`账本及对应summary.csv，`models/`保存固定权重、参数、训练边界、入选因子和验证/测试预测，`benchmarks/`保存同期等权基准。

- `results/universe_comparison.csv`：90个候选的验证多空年化及2018各项结果，报告主评多空。
- `results/validation_candidates.csv`：选池、选期限的全部训练期验证候选。
- `results/selected_cases.csv`：仅按验证多空年化选出的十项策略，含2018多空累计、年化、夏普及回撤。
- `results/decile_returns.csv`：训练期验证与2018各900条十分组绩效，含累计、年化和夏普。
- `results/benchmark_summary.csv`、`benchmark_month_returns.csv`：等权累计及月度收益。
- `results/best_parameters.csv`、`feature_selection_summary.csv`、`training_summary.csv`：9个最终模型汇总。
- `results/outer_validation_summary.csv`：27个外层模型的参数、树数、因子及信息截止；各模型的`outer_validation/Q1`等子目录保存独立搜索、权重和筛选记录。预测逐行保存`ParameterAsOf`、`SelectionMaxLabelEnd`、`TrainMaxLabelEnd`，均不晚于信号日`TradingDay`。
- `results/validation.json`：现金账本、费用、标签日期、模型冻结及选型范围核验。
- `results/execution/`：42项固定审计对象情景，以及验证选定模型的价格约束基准、5%/10%/20%借券费及无约束对照，共47项；保留每日账本、独立隔夜/日内归因和价格核验。固定审计对象的两种执行模式各包含反向、1/5/20日滞后、5%/10%/20%借券费、10个随机种子及其中3个相同种子的零交易费对照。
- `results/execution/cdpdp_rerun.csv`、`cdpdp_selected.csv`、`cdpdp_rerun.json`：v12从当前因子输入重新分组并执行的72项CDPDP/CDPDP′回测、验证选型及溯源；`cdpdp_daily_attribution.csv`与`cdpdp_attribution.csv`为全A股12个测试案例的独立归因。本轮未改因子定义、0值约定或代码，2018无价格约束的最高夏普分别为1.19与1.73；此前5.17属于CDPP，不属于CDPDP系列。

报告主评多空收益。每项策略同一张图的上半部叠加G1—G10、多空和股票池等权净值，下半部保留十分组费后累计收益柱状图；全部图注明股票池与期限。等权只作市场背景，两种组合的名义敞口不同。三池其他测试结果完整保留，但不根据2018最高收益替换选图组合。

## 合成因子训练与lag

训练标签是每只股票未来N交易日开盘收益减同日可用标签的截面均值；不是组合多空收益或RankIC数值。训练损失保持`reg:squarederror`，验证RMSE用于早停，RankIC稳定性选择超参数；股票池和调仓期限按嵌套时间验证、价格约束下的费后多空年化选择。本轮复用已核验的v10权重、重新预测及回测。2018不进入本轮学习或选型函数，但同一历史区间已多轮研究，不能把它当作未经研究接触的新增时期证据。

- 特征附加lag为0：T收盘后已知的因子，未额外整体shift。
- 执行lag为1个交易日：T收盘信号于T+1开盘执行。
- 标签跨度N为5/10/20：从T+1开盘持有至T+N+1开盘，退出偏移分别为6/11/21。
- 因子10/20/160日计算窗口是回看窗口，不是执行lag；所有偏移按交易日历。

实际训练末日和上述lag值见`results/training_lag.csv`。所选十项策略的100条柱状图数值见`results/selected_decile_returns.csv`。十分组累计收益之差不等于独立多空账本收益。
