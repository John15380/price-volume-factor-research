# 因子定义再次复核

结论：上一版仍不能称为“完全按照研报”。理想振幅遗漏了原始研报的有效日细则；偏度、尾盘收益也不能归为这四篇研报的因子。已修正理想振幅，并重跑完整单因子、配对、XGBoost和ICIR；旧结果冻结保留。

## 查到的实质遗漏：理想振幅

本地20210924《独家量价因子的高频测试》第8页只是定义摘要。按其引用继续核对20200516《振幅因子的隐藏结构》第5页后，确认原始细则为：

1. 回看最近20个交易日，日振幅为 `High/Low-1`。
2. 有效日剔除停牌及一字涨跌停日。
3. 窗口内有效日少于10天才将因子置空。
4. 按收盘价高低排序，分别取25%有效日计算振幅均值，采用高价端减低价端，低值做多。

上一版主公式、第4步的方向均正确，但错误地要求20日振幅全有效；同时未从历史排序窗口排除一字涨跌停。不能以信号当天已经剔除停牌来替代历史窗口内的有效日处理。

新版保持20日窗口位置，排除无效日后计算，**不会把窗口向前延长至凑满20个有效日**。有效日为10—20天；每端日数取 `floor(n_valid*0.25)`。舍入及价格并列处理原文未明确，当前保留确定性排序约定，不能把这部分宣称为原报告公开源码的精确再现。一字涨跌停使用历史原始最高/最低价相同且收盘贴实际涨跌停价识别，不把所有无振幅日都当作一字板。信号时点只使用T日及过去状态。

原始报告已保存为 [20200516.pdf](source_reports/20200516.pdf)，关键页5—7；[来源记录](source_reports/manifest.json)保留下载地址和校验值。

## 仍不能称为完全复现的实现约定

- 聪明钱首个分钟使用该分钟开收盘收益，其余使用相邻分钟收盘收益；跨除权日统一价格/份额单位，20%边界按比例截断。研报没有公开第一分钟、零成交和边界插值的代码细则。
- 条件相关不足3对或零方差时延续原code2置0，整日缺行情保持缺失。Pearson相关在退化样本下本来没有定义，置0是实现约定，不能称为研报要求。
- 截面去极值采用5倍MAD，股票上市年龄用首次有效报价近似；开盘执行、保守涨跌停撮合及借券/融资假设仍与研报数据条件有差别。
- 主样本为2016—2018动态中证500，而开源主要报告使用更长的全A区间。本轮新增全A理想振幅对照，避免仅凭中证500的收益断定公式错误。
- 不采用当天收盘建仓来提升收益；不改多空方向、不调整25%/10日/20%等参数追求收益接近研报。

- `numeric_reference_checks.json`：固定3只股票×10天，独立NumPy核对聪明钱和四象限相关，误差在浮点精度范围。这证明所述实现约定下的算术一致，不替代缺失的研报数据约定。
- 58项测试通过；新增测试覆盖有效日不足10、10—19天仍可计算、一字板/停牌识别，以及不将理想振幅专属规则套到其他因子。

结果表将在 `report_definitions/` 中从新账本自动生成；修正定义不保证回测收益提高，前后结果均原样保留。
